# Supporting records

Preserve original user-submitted notes here only when approved for public repository storage. Suggested name: YYYY-MM-DD-short-title.md. Keep original wording intact; link the resulting reading note back to its record.

Everything committed to a public repository is public, including files excluded from the website and Quarto drafts. For unapproved notes, use the conversation or an explicitly chosen private location; do not commit them.

Add experiment run manifests and raw outputs when actual experiments begin. Do not create empty bookkeeping logs or invented entries.
